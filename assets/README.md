# readme artwork

art for the root `README.md`. nothing here is loaded by the app. the app's own
assets live in `apps/mobile/assets/`.

| file | status | notes |
|---|---|---|
| `logo_light.png` | present | the mark in the `<h1>`, rendered at 32px |
| `logo_dark.png` | present | dark-mode counterpart, currently unused by the readme |
| `hero.png` | **missing** | a wide product shot under the intro. ~1600px wide, matches what `stera-sdk` has |
| `app-qr.svg` | **missing** | qr pointing at https://fpvlabs.ai/app, floated right at 96px |

drop the two missing files in and uncomment their blocks in the root readme.

the logos are regenerated by `bun run brand:apply`, so a fork gets its own mark
here instead of Stera's. see `packages/brand/transforms/assets.ts`. hero and qr
are not generated, a fork has to supply its own.
